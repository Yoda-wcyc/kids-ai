# 小朋友學AI

給孩子的互動學習頁。每一頁都是一個小關卡，點進去就能玩，不需要登入，也不蒐集任何資料。

線上網址：https://yoda-wcyc.github.io/kids-ai/

## 頁面

- [AI 會唬爛](https://yoda-wcyc.github.io/kids-ai/%E5%B0%8F%E6%9C%8B%E5%8F%8B%E5%AD%B8AI-AI%E6%9C%83%E5%94%AC%E7%88%9B.html)：AI 有時會很有自信地說錯。學會三招不被騙：自己查、問大人、多找一個地方對答案。
- [怎麼問得好](https://yoda-wcyc.github.io/kids-ai/%E5%B0%8F%E6%9C%8B%E5%8F%8B%E5%AD%B8AI-%E6%80%8E%E9%BA%BC%E5%95%8F%E5%BE%97%E5%A5%BD.html)：同一件事，問法不同答案就差很多。練習講清楚、給背景、說形式，讓 AI 真的幫得上忙。
- [秘密不能說](https://yoda-wcyc.github.io/kids-ai/%E5%B0%8F%E6%9C%8B%E5%8F%8B%E5%AD%B8AI-%E7%A7%98%E5%AF%86%E4%B8%8D%E8%83%BD%E8%AA%AA.html)：分清楚哪些話可以跟 AI 或網路上的人說，哪些能找到你本人的資料要收好。
- [數學-天平解方程式](https://yoda-wcyc.github.io/kids-ai/%E6%95%B8%E5%AD%B8-%E5%A4%A9%E5%B9%B3%E8%A7%A3%E6%96%B9%E7%A8%8B%E5%BC%8F.html)：用天平一步一步看懂解方程式：兩邊做一樣的事就不會歪，數字搬過等號符號要翻過來。
